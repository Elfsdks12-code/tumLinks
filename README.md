# Mein Quick Portal

This wasn't an exhausting or overly complex project. I simply wanted to build a single hub using Python, CSS and HTML where I could easily access all my daily links, because opening everything separately was getting tedious. 

At the end of the day, computer science is all about making our lives easier—and building this tool reminded me of that once again.

 Built With
* Python (Flask)
* HTML & CSS
